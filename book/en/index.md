---
title: "From Field to Code: Spatial SQL from Scratch"
---

PostgreSQL and PostGIS from scratch.

This book teaches databases to readers who have never worked with one. We start with the basics: what a database is, how to install one on our own computer and how to ask it questions in SQL. Then we move on to geographic data with PostGIS: points, lines and polygons, distances, buffers and overlays between layers. Everything runs on real data from Asturias and from the Pajares project on forests, storms and power lines.

The code in every lesson can be copied and run as it is.

*Work in progress. Lessons are published as they are written.*
