# Data passport

The data are not stored in this repository. Small derived files that the lessons need will be published as an open **data package** on Zenodo, with a DOI. This file says, for every dataset the book uses, where it comes from, under which licence, when it was downloaded and how to get it again.

The working coordinate system of the book is **ETRS89 / UTM zone 30N (EPSG:25830)**.

Status of each entry: **checked** (source, licence and file verified) or **to check** (to be verified before the first lesson that uses it).
